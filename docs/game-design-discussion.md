## 二、世界观与美术

| 维度 | 决策 | 参考 |
|---|---|---|
| 世界观 | **现代乡村 / 山村田园** | 温馨治愈，贴近生活 |
| 美术风格 | **Q版俯视 2.5D** | 类《星露谷物语》《略略略》视角，俯视 45° 或等距视角 |

## 三、核心更新：同步 45° 视角适配、工具交互逻辑。

### 3.1 时间系统  采用 WorldTimeManager 驱动制。现实 10 分钟 = 游戏 1 天。天结束时（DayEnd）触发全局生长计算，支持离线补偿。

### 3.2 季节与天气
- **完整四季循环**：春种夏长秋收冬藏
  - 不同季节可种植不同作物
  - 某些作物跨季节会枯萎
- **天气系统**：晴/阴/雨/雪
  - 雨天自动浇水（节省行动力）
  - 特殊天气触发特殊事件（暴雨/寒潮/丰收季）
  - 天气对农作物收益有加成/惩罚

### 3.3 核心玩法模块（按优先级）

```
MVP 阶段（第一版）：
  ✅ 种植 / 收获 —— 开垦、播种、浇水、施肥、收获
  ✅ 基础地图渲染 —— 格子系统、地块状态

第二阶段：
  ✅ 建筑 / 加工 —— 加工坊、仓库、磨坊，原材料→高价值产品
  ✅ 养殖 —— 鸡、猪、牛；需喂养饲料，产出鸡蛋/牛奶/肉类

第三阶段：
  ✅ 探索 / 挖掘 —— 探索地图新区域，挖矿、采集野生资源、钓鱼
  ✅ 社交内容（集市/任务/每日活动）
```

### 3.4 成长驱动
- **等级 + 解锁**为核心成长线
  - 升级解锁新作物品种、新建筑、新地图区域
  - 线性成长感强，玩家目标明确
- 经验来源：收获作物、完成任务、加工产品、喂养动物

## 五、数据与存档

| 阶段 | 方案 |
|---|---|
| MVP / 早期 | **纯本地存档**（Cocos Creator LocalStorage / JSON 文件） |
| 中后期 | 接入云存档（微信云开发 or 自建后端），支持多端同步 |

**本地存档需持久化的数据：**
- 地图格子状态（每格：地块类型/作物ID/种植时间/生长阶段）
- 玩家数据（等级/经验/金币/背包）
- 建筑状态
- 游戏内时间（当前日期/季节/天气种子）
- 任务进度 / NPC 好感度

## 六、技术架构方向

基于项目已有 MVC 框架，按模块拆分：

```
game/
├── farm/        农场地图模块（格子管理、地块操作）
├── crop/        作物模块（配置表、生长状态机）
├── livestock/   养殖模块
├── building/    建筑/加工模块
├── explore/     探索模块
├── player/      玩家数据（等级/背包/金币）
├── time/        游戏内时间（日期/季节/天气）
├── quest/       任务系统
└── shop/        集市/商店
```

事件系统（`GameEvents.ts`）需完全重写为种田事件，原 Slot 事件全部清除。

## 七、MVP 范围（第一版可玩目标）

> 目标：**2 周内做出核心种植循环，能感受到「种下去 → 等待 → 收获」的完整反馈**

**MVP 包含：**
- [ ] 农场地图渲染（固定区域，若干格子）
- [ ] 地块操作：开垦 → 播种 → 浇水 → 收获
- [ ] 1~2 种作物（萝卜/小麦），有生长阶段动画
- [ ] 游戏内时间推进（按帧或按操作推进天数）
- [ ] 玩家金币：收获后卖出换金币
- [ ] 基础 UI：背包、金币显示、操作提示

**MVP 不包含：**
- 季节/天气（第二版加）
- 建筑/加工/养殖（第二版加）
- NPC/任务（第二版加）
- 探索（第三版加）
- 云存档（后期加）

## 八、玩法细节决策（第二轮讨论）

### 8.1 主角操控方式
- 主角操控与视角：

- 视角：采用 45° 等距视角 (Isometric)，逻辑网格 125x98。

- 移动：摇杆驱动（PlayerMover）+ 平滑摄像机跟随（CameraFollow），支持鼠标滚轮动态缩放（Zoom）。

> ⚠️ 架构影响：需要 `PlayerController`（寻路/移动）+ `PlayerAnimator`（动画状态），是独立模块，不可跳过

### 8.2 时间流速
- **现实 10 分钟 = 游戏 1 天**
- 1 个游戏季节 = 30 天 = 现实 5 小时累计在线
- 1 个游戏年 = 4 季 = 现实约 20 小时累计
- 典型作物生长周期参考：

| 作物 | 游戏天数 | 现实等待时间 |
|---|---|---|
| 萝卜（快熟） | 3 天 | 30 分钟 |
| 小麦（中等） | 7 天 | 70 分钟 |
| 番茄（多次收） | 14 天首收 | 140 分钟 |
| 蓝莓（季节性） | 20 天 | 200 分钟 |

### 8.3 初始地图规模
- **初始农场：4×4 = 16 格**
- 开局给玩家 4 格已开垦土地，其余 12 格为荒地（需开垦）
- 后续等级解锁扩展策略：

```
Lv1~5   : 农场区 4×4（16格）
Lv6~10  : 农场区扩展到 6×6（+20格）
Lv11~15 : 解锁果园区（独立区域）
Lv16+   : 解锁牧场区 / 矿洞入口
```

- 地图总体为开放大地图，各功能区（农田/果园/牧场/村庄/探索区）通过场景切换或无缝滚动连接

### 8.4 加工系统配方
- **固定配方**：N 个原料 → 1 个产品，无随机性，无参数影响
- 加工需要对应建筑，建筑有加工时间（游戏内时间计算）
- 配方示例（待完整规划）：

| 建筑 | 输入 | 输出 | 加工时间 |
|---|---|---|---|
| 磨坊 | 小麦 ×3 | 面粉 ×1 | 1 天 |
| 烤炉 | 面粉 ×2 + 鸡蛋 ×1 | 蛋糕 ×1 | 2 天 |
| 压榨机 | 番茄 ×5 | 番茄酱 ×1 | 1 天 |
| 牛奶坊 | 牛奶 ×3 | 奶酪 ×1 | 3 天 |

### 8.5 NPC 设计
- **MVP 阶段仅 2 个 NPC**，后续版本再扩展
- **NPC A：指导老人（村长/师傅）** — 负责新手引导、主线任务发布
- **NPC B：商人（杂货铺老板）** — 负责种子购买、农产品出售、道具采购
- 后续版本规划（第二阶段）：加入 5~8 个村民 NPC，各自有简单好感度系统

### 8.6 美术资源方案
- **三管齐下**：AI 辅助生成 + 自制修改 + 购买第三方素材
- 分工策略：
  - 地图格子/地块贴图：购买 2.5D 种田主题素材包（优先）
  - 作物生长动画帧：AI 生成原型图 → 手工修帧
  - UI 界面元素：自制（Figma 设计）
  - 主角/NPC：购买可商用角色素材 or AI 生成后修改
- MVP 阶段：**先用占位色块开发，功能通后换正式美术**

## 九、核心数值框架（草案）

> 数值需要在 MVP 实现后实际调试，以下为初始参考值

### 作物经济循环
```
萝卜：种子 10 金币 → 收获卖出 35 金币 → 净利润 25 金币 / 30 分钟
小麦：种子 20 金币 → 收获卖出 80 金币 → 净利润 60 金币 / 70 分钟
番茄：种子 50 金币 → 每次收获 60 金币 × 3次 → 净利润 130 金币（可多次收获）

Lv2 → Lv3 : 250 EXP
每级所需 EXP ≈ 上一级 × 1.8（指数增长）
```

## 十、玩法细节决策（第三轮讨论）

### 10.1 主角移动方案
- 放弃 UI 弹窗种植。改为 “快捷工具栏”模式。玩家选中“种子袋”或“锄头”工具，在角色面前的格子点击使用，通过 ToolManager 触发 FarmController 逻辑。

> ✅ 架构影响：MVP 阶段无需 `PathfindingSystem`，`PlayerController` 仅需处理「传送到目标格旁 + 触发操作」

### 10.2 探索区玩法
- **纯资源采集**，无战斗
- 玩家进入探索区后，点击资源节点（矿石/野菜/钓鱼点）触发采集动画，获得资源
- 探索区资源每游戏日刷新一次
- 引入**体力/行动点制**：每日有固定行动点，探索消耗行动点，耗尽后当日无法继续探索
  - 行动点制为探索区带来「今天去哪采什么」的策略决策感

### 10.3 货币与资源体系
- **双资源体系：金币 + 特殊材料**
- 金币：日常流通货币，出售农产品获得，用于购买种子/工具/建筑材料
- 特殊材料：探索区专属产出（矿石、蓝晶石、古木等），用于解锁高级建筑/配方
- 特殊材料不可直接购买，只能通过探索获得，强化探索区独特价值

```
资源获取路径：
  农业线：种植收获 → 金币 / 加工品
  探索线：探索区采集 → 特殊材料 → 解锁高级内容
  两条线互相依赖（高级加工需要特殊材料盖建筑，高级作物卖出更多金币）
```

### 10.4 作物规划
- **MVP 阶段先做 4 种作物**，后期逐步扩展到 16~24 种
- MVP 作物（4种，覆盖基础体验）：

| 作物 | 季节 | 生长天数 | 收获次数 | 种子价 | 卖出价 |
|---|---|---|---|---|---|
| 萝卜 | 春 | 3天 | 1次 | 10金 | 35金 |
| 小麦 | 春/秋 | 7天 | 1次 | 20金 | 80金 |
| 番茄 | 夏 | 14天首收 | 3次 | 50金 | 60金/次 |
| 南瓜 | 秋 | 10天 | 1次 | 40金 | 150金 |

- 后期扩展方向：每季各 4~6 种，冬季以温室/特殊作物为主

### 10.5 养殖动物
- **三种动物：鸡、牛、羊**
- 各动物产出与喂养设计：

| 动物 | 产出 | 喂养 | 生产周期 | 解锁等级 |
|---|---|---|---|---|
| 鸡 | 鸡蛋 | 普通饲料 | 1天/个 | Lv5 |
| 牛 | 牛奶 | 小麦/牧草 | 2天/桶 | Lv10 |
| 羊 | 羊毛 | 牧草 | 3天/团 | Lv15 |

- 动物未喂养时产出暂停，但不会死亡（降低玩家焦虑感）

### 10.6 背包系统
- **格数无限 + 叠加上限**（每格同种物品最多叠加 999 个）
- 玩家不用担心背包爆满，专注于游玩体验
- 仓库建筑：独立于背包，用于存放大量原材料，可升级扩容上限

### 10.7 建筑体系
- **四类建筑**：

| 类型 | 建筑示例 | 核心功能 |
|---|---|---|
| 加工建筑 | 磨坊、烤炉、压榨机、奶酪坊 | 原料 → 高价值产品 |
| 仓库 | 仓库 Lv1~3 | 扩大存储上限 |
| 养殖舍 | 鸡舍、牛棚、羊圈 | 容纳对应动物 |
| 主角居所 | 小屋 Lv1~3 | 装饰系统，放置家具/装饰品 |

- 建筑建造需要：金币 + 特殊材料 + 达到对应等级
- 建筑占地：每栋建筑占 2×2 或 3×3 格，需在地图上选址放置

### 10.8 节日活动
- MVP 及第二阶段暂不开发
- 第三阶段规划：春节/中秋/丰收节 3 个大节日，每个节日有限时任务和专属奖励

## 十一、完整系统全景图

```
游戏主循环：
  [种植循环]     开垦 → 播种 → 浇水(+施肥) → 等待生长 → 收获 → 出售/加工
       ↓                                              ↑
  [时间推进]     游戏内时间流逝 → 季节/天气变化 → 影响作物/事件
       ↓
  [资源管理]     金币 ←→ 购买种子/建筑        特殊材料 → 解锁高级内容
       ↓                                     ↑
  [探索系统]     消耗行动点 → 采集矿石/野菜/钓鱼 → 特殊材料入库
       ↓
  [加工系统]     农产品 + 建筑 → 加工品（更高售价）
       ↓
  [养殖系统]     饲料喂养 → 动物产出（鸡蛋/牛奶/羊毛）→ 加工/出售
       ↓
  [成长系统]     收获/任务/加工 → 经验 → 升级 → 解锁新内容
       ↓
  [NPC互动]      商人（买卖） + 村长（任务/剧情）
```
